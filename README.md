# AI-Powered Customer Segmentation & Customer Lifetime Value Analysis

## 📌 Project Overview

This project analyzes customer purchasing behavior using **RFM Analysis, K-Means Clustering, and Customer Lifetime Value (CLV)**.

The goal is to identify different customer segments, estimate their lifetime value, and provide actionable business recommendations for each segment.

---

## 🎯 Project Objectives

- Analyze customer purchasing behavior
- Perform data cleaning and exploratory data analysis
- Calculate Recency, Frequency, and Monetary (RFM) metrics
- Segment customers using K-Means clustering
- Identify business-oriented customer segments
- Calculate Estimated Customer Lifetime Value (CLV)
- Generate business recommendations based on customer segments

---

## 📊 Dataset

The project uses transaction-level customer data.

- **Total Transactions:** 5,020
- **Unique Customers:** 750

The transaction data is transformed into customer-level metrics for segmentation and CLV analysis.
